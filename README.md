# NKOON Project

## About the Project

NKOON is a project developed as part of a practical realization of a topic related to **Alterity (L'altérité)**.

The main purpose of this project is to better understand the user's psychological and emotional state through their input, identify what they might be feeling, and provide an appropriate and meaningful output based on their emotional needs.

## Project Objective

The project aims to:

- Understand the user's psychological and emotional state.
- Recognize and interpret the feelings expressed by the user.
- Provide a suitable response according to the user's emotional state.
- Create a more empathetic and human-centered interaction.

## Why We Created This Project

We developed NKOON to explore how technology can contribute to understanding human emotions and individual experiences.

Through this project, we wanted to understand the importance of recognizing others' feelings, considering different perspectives, and responding in a way that respects each user's emotional experience.

## Technologies Used

- Python

## Project Goal

Our goal is to explore the relationship between technology, emotions, and human understanding, while applying the concept of alterity in a practical way.
